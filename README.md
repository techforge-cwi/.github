# .github

Org-wide settings for TechForge. Nothing here is code.

| File | What it does |
|---|---|
| `profile/README.md` | The public page at [github.com/techforge-cwi](https://github.com/techforge-cwi). Members see the version in `.github-private` instead. |
| `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md` | Defaults for every TechForge repo that doesn't have its own copy. |
| `.github/ISSUE_TEMPLATE/` | The Bug, Idea, and Task forms people see when they open an issue in any repo without its own templates. |
| `.github/pull_request_template.md` | The checklist that pre-fills every new pull request. |

This repo has to stay **public** for the profile page and defaults to work.
