# Getting help

| You need | Go here |
|---|---|
| Help with a project, or you're stuck on code | That project's channel in the TechForge Discord |
| Something is broken | Open an issue with the **Bug report** form |
| You have an idea | Open an issue with the **Idea** form |
| GitHub access, invites, or the Discord bot | Ask any officer on Discord |
| Learning git, Python, or AI | [resources](https://github.com/techforge-cwi/resources) |
